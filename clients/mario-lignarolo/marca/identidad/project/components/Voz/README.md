# Voz

La serif (Cormorant Garamond) es la voz de Mario. Se usa en tres sitios:

- **`voz`:** titulares en primera persona, más íntimos que `display` (Origen, Emprendimiento), y en itálica la pregunta que cierra una sección, centrada y con mucho aire (`space-10`) alrededor.
- **`voz-italica`:** frases en itálica dentro de una sección (el statement de Psicocibernética) y notas al pie de un póster.
- **`voz-xl`:** la frase de un banner.

Solo para palabras de Mario, literales y con fuente. Nunca para interfaz, botones ni datos. La itálica se reserva para preguntas y notas, como el «*If you have a body, you are an athlete» de Nike.
