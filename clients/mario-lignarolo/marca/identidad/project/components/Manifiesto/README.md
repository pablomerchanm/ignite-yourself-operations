# Manifiesto

Es la lectura guiada de Monolog: un texto largo de Mario en `statement` (Geist 600), todo a un solo tamaño, cuyas palabras se encienden de una en una al cruzar la línea de lectura.

- **Palabras apagadas:** opacidad `apagado` (0,16). Las encendidas, en `tinta` plena.
- **Columna índice:** lleva la etiqueta y el progreso: una pista de 1 px (`linea`) que se llena en `tinta`, dos flechas que saltan de párrafo y el contador en mono `(02/05)`.
- **Ancho:** el texto vive en la columna de contenido (4–12), con un máximo de 21em para que la línea respire.

Úsalo para los textos que hay que leer despacio: el origen, el statement de Psicocibernética, el titular de Hipertrofia del Ser. Como mucho, tres por página.

Con movimiento reducido o sin JavaScript, todo el texto aparece encendido y sin pin.
