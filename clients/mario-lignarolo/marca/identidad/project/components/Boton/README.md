# Botón

El botón de Monolog: la etiqueta y, pegada, una caja con la flecha en el color contrario. Radio `fino` (2 px).

- **Principal:** relleno `relleno`, texto `sobre-relleno`. Uno por sección como mucho, para el paso que la sección pide.
- **Fantasma:** filete `linea-fuerte`, caja rellena. Para el segundo paso.
- **Enlace:** texto `ui` subrayado fino con ↗. Para salidas secundarias (vídeos, «todas las conversaciones»).

Reglas:

- **Etiqueta:** en caja de frase, con un verbo delante, tal como la escribe el spec («Explorar Psicocibernética», «Leer Hipertrofia del Ser»).
- **Flecha:** ↗ cuando el enlace sale de la web y → cuando lleva a otra parte de la página.
- **Al pasar el ratón:** el botón sube 2 px y la flecha avanza.
- **Foco:** anillo `foco` de 2 px.
