# Fila

Una lista con filetes, al modo de Monolog. Sirve para las conversaciones, los índices y el menú del pie.

Columnas: el número en mono, el título en `title`, el dato (canal o duración) en mono y la flecha. Entre filas, un filete `linea` de 1 px. Al pasar el ratón, la fila entra `space-4` hacia la derecha.

Usa la fila cuando el contenido es una lista y no una galería. Si cada elemento tiene una imagen que importa, usa la entrada.
