# Cabecera

La cabecera es una sola línea sobre la portada, con tres partes:

- **Izquierda:** el logotipo, de 20–22 px de alto.
- **Centro:** el menú en `ui`, al 86 % de opacidad.
- **Derecha:** «Contacto» como botón principal.

Se compone con la retícula de Monolog (logo, menú centrado, acción) y la sobriedad de Nike.

- **Al bajar:** se queda fija, con el fondo transparente. Sobre secciones claras toma el tema claro: el logo en negro y el botón invertido.
- **En móvil:** el logo y un botón «Menú». El menú se abre a pantalla completa, con los enlaces en `display`.
- **Contenido:** el menú lleva solo las secciones del spec. Nada de iconos sociales en la cabecera.
