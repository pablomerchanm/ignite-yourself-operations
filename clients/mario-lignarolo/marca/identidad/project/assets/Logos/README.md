# Logos

Todos de una sola tinta, sin `currentColor`: el sufijo dice el color.

- `-blanco` va en hueso (#ECEBE6) y es para fondos oscuros.
- `-negro` va en negro (#0B0B0A) y es para fondos claros.

| Archivo | Uso |
| --- | --- |
| `mario-lignarolo-blanco.svg`, `mario-lignarolo-negro.svg` | Logotipo de Mario (vector del PNG de Pablo). Menú y firma del pie. |
| `hds-logo-horizontal-*.svg` | Cabecera de Hipertrofia del Ser, horizontal: abre su sección en la web. |
| `hds-logo-vertical-*.svg` | Cabecera de Hipertrofia del Ser, vertical: portadas y piezas cuadradas. |
| `hds-simbolo-*.svg` | Símbolo grande (filete fino), de 64 px en adelante. |
| `hds-simbolo-pequeno-*.svg` | Símbolo pequeño (trazo grueso), de 16 a 48 px y avatar. |

Hipertrofia del Ser es una propuesta pendiente de Mario.
